# Stapler, c. 1987 — The One-Line Placard

Entry for **Office Artifacts: The One-Line Placard Contest** on
[make.fun](https://make.fun/c/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2).

A program that writes a single museum placard line (at most 180 characters)
for an ordinary office stapler, treated as an ancient artifact, to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

## The placard

> Stapler, c. 1987. Iron and regret. Bound 14,203 memos; the last, unread, still in its jaw. Gift of the Accounts Department.
